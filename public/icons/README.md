# App icons

The Blobbi app icon family (Home, Island, Pixel, Farm; Rumble keeps its own) is generated by Blobbi Pixel's
`scripts/app-icons.ts` (`npx tsx scripts/app-icons.ts --family <dir>` in the blobbi-pixel repository), which follows
Rumble's composition rules: the canonical Blobbi on a light background, 80 % of an "any" icon, 60 % of a maskable one.

- `icon-source.svg`: the editable source of this app's icon. To change the icon, edit it and rasterize it again with
  `npx tsx scripts/app-icons.ts --svg icon-source.svg --out .` (the 192, 512, 180 and 32 px PNGs), or change the
  generator and run the family again.
- `icon.svg`: the same icon with rounded corners, for the browser tab.
- `icon-192.png`, `icon-512.png`: the manifest's "any" icons. `icon-512-maskable.png`: the maskable one.
  `apple-touch-icon.png`: 180 px, opaque. `favicon-32.png`: the tab.
- `worlds/<world id>.png`: the other apps' own 192 px icons, copied as they are, for the World Travel cards
  (Rumble's comes from blobbi-3d `public/icons/icon-192.png`).
